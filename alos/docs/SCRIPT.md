# DisruptionOps – launch film script (≈55 s)

Structure follows the Madison reference: **problem → pain → "meet" reveal → product proof in 3 beats → numbers → tagline**.
Every figure is from the live app (`DATASET.md`). Voice: neural female narrator (edge-tts `en-US-AvaNeural`), one clip per line
so the beat map can use exact durations (`alos/audio/vo/lines.json`).
